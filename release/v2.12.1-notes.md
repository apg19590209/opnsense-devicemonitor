# Device Monitor v2.12.1

v2.12.1 is a release-identity repair for v2.12. It contains no runtime feature
changes.

## Repair

- The installer now identifies and verifies
  `release/v2.12.1-runtime.manifest`, a 41-row payload.
- The manifest digest, row count, and derived target totals now agree: 62
  targets on an upgrade and 63 on a fresh installation.
- The installer reports version `2.12.1` and accepts an installed `2.12`
  predecessor.
- A failed install now snapshots and restores the core-locale state directory,
  including pristine catalogues, ownership records, metadata and files that
  did not exist before the attempt.
- Bundle rebuilds canonicalise tar headers and use a fixed gzip header plus a
  stored-block stream, so repeated builds produce the same bytes.
- The English and existing translations now include the settings labels already
  referenced by the UI, completing the language-acceptance catalogue without
  changing runtime behaviour.
- The About page identifies this release as `v2.12.1`.
- `release/v2.12-runtime.manifest` remains byte-unchanged as the historical
  v2.12 release input. The v2.12 tag and asset remain immutable.

## Installation

Download the `dm-v2.12.1-runtime.tar.gz` release asset. It contains only the
installer and plugin runtime sources. Extract it on OPNsense and run
`sh install.sh --host EXACT_FIREWALL_HOSTNAME`. The installer verifies every
payload digest and mode before replacing files, takes a retained rollback
backup, verifies the installed files, restarts `configd`, and restarts Device
Monitor when it was already running. Use `--check` for a preflight that changes
nothing.

Existing device history and configuration are preserved. No user database,
configuration, passwords, or backups are included in the release asset.
