# Device Monitor v2.10

## Changes

- Nine major UI language translations (German, Spanish, French, Italian, Japanese, Dutch, Portuguese, Russian and Simplified Chinese) in addition to the existing English and Czech. All translations other than English and Czech are machine-generated; native-speaker corrections are welcome.
- Translated text used in page JavaScript is no longer HTML-escaped before encoding. Pages read the raw translated value and JSON-encode it, so translations containing apostrophes, quotation marks, backslashes, line breaks or `</script>` render exactly and cannot break or inject into the surrounding script.
- Per-network-identity service email alerts with clearer delivery warnings.
- Opt-in targeted discovery of TCP ports 1–65535 on one monitored device at a time, with a 120-second limit, weekly per-device scheduling, and scan history. UDP ports, including WireGuard, are outside this scan.
- Explicit monitored-interface scoping, with no scanning when no interface is selected; loopback targets are excluded.
- Responsive infrastructure and change tables, with keyboard focus retained across Devices refresh.

## Language support

- Catalogues are installed and compiled for German (`de_DE`), Spanish (`es_ES`), French (`fr_FR`), Italian (`it_IT`), Japanese (`ja_JP`), Dutch (`nl_NL`), Portuguese (`pt_BR`), Russian (`ru_RU`) and Simplified Chinese (`zh_CN`), alongside English (`en_US`) and Czech (`cs_CZ`).
- Every build validates the nine added languages across the 10 Device Monitor pages and 448 message ids per language, checking that each page renders the selected language with no English fallback and no JavaScript-encoding failure. The 120 rendered script blocks pass Node syntax checks, including a hostile translated string holding quotes, backslashes, newlines, `</script>` and ampersands, which is preserved exactly.
- Known limitation: Dutch (`nl_NL`) cannot be selected from `System → Settings → General → Language`, because OPNsense's own language list (19 languages) does not offer Dutch. The Dutch catalogue and the `nl_NL.UTF-8` locale are installed and the pages render correctly in Dutch once that language is active.

## Installation

Download the `dm-v2.10-runtime.tar.gz` release asset. It contains only the installer and plugin runtime sources. Extract it on OPNsense and run `sh install.sh --host EXACT_FIREWALL_HOSTNAME`. The installer checks its manifest and current installation, takes a retained rollback backup, verifies the installed files, restarts `configd`, and restarts the Device Monitor daemon if it was running. Use `--check` for a preflight without changing installed files.

Existing device history and configuration are preserved. The installation backup remains on the firewall under `/var/backups/devicemonitor/`. No user database, configuration, passwords, or backups are included in the release asset.
